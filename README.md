## Current Stage
Fine tuning Software and making Hardware

## Project Goals

- **Real-Time Target Detection**: Architect a low-latency CV pipeline to autonomously identify and classify targets in controlled lighting
- **Multi-Axis Tracking**: Implement spatial tracking to continuously maintain target lock across 3D coordinates.
- **Trajectory Prediction Models**: Formulate models to forecast non-linear and linear target motion and optimize engagement timings.
- **Predictive Ballistics & Trajectory Estimation**: Develop models to calculate target lead positions and projectile flight times.
